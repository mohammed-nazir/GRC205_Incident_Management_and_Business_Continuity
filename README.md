# GRC205: Incident Response Planning

**Course:** GRC205 — Incident Response Planning  
**Scenario:** Northbridge Skills Institute — suspected ransomware incident  
**Author:** Mohammed Nazir  
**Status:** Prepared for academic review

## Project overview

This repository contains my completed GRC205 Incident Response Planning assignment. It applies a structured incident-response approach to a fictional ransomware incident affecting finance systems, shared files, backups, and an online learning portal.

The assignment is organized around six tasks:

1. Incident classification and initial assessment
2. Incident response plan and team responsibilities
3. Response playbook and evidence preservation
4. Communication and escalation
5. Tabletop exercise and improvement plan
6. Reflection on a healthcare ransomware case study

## Key areas covered

- Evidence-led incident timeline and severity assessment
- Confidentiality, integrity, and availability impacts
- Initial containment and prioritization of critical systems
- Incident-response roles, responsibilities, and escalation
- Evidence handling and chain-of-custody documentation
- Backup validation and safe recovery considerations
- Stakeholder communication and tabletop exercise design
- Lessons learned and corrective-action tracking

## Important note

The scenario and organization are fictional and are used for educational purposes. This repository is an academic exercise, not an operational incident-response procedure. Real incidents should be handled under applicable organizational policies, legal obligations, and the direction of authorized incident responders.
