# Contributing

Contributions should improve accuracy, accessibility, citation quality, or presentation while preserving the academic record.

## Suitable contributions

- Correct typographical or formatting errors
- Fix broken internal links
- Improve Markdown accessibility
- Clarify the distinction between confirmed observations and hypotheses
- Suggest authoritative references or citation corrections
- Identify inconsistencies between the Markdown and original Word submission

## Contribution process

1. Open an issue describing the proposed correction.
2. Create a focused branch from the default branch.
3. Make the smallest change necessary.
4. Explain whether the change is editorial or substantive.
5. Confirm that Markdown links and tables render correctly.
6. Submit a pull request using the repository template.

Do not add confidential information, real credentials, malware, unsupported breach claims, or copied academic work.
